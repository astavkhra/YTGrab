[00:00:02] 📃 how_it_works

Running in under a minute

step 1/3

Download & unzip

Grab YTGrab.zip with the button above and extract it anywhere — Desktop, D: drive, a USB stick. No installer, no admin rights.

step 2/3

Run YTGrab.exe

Double-click it. If Windows shows a blue "protected your PC" screen, click More info → Run anyway — that's normal for independent apps.

step 3/3

Paste, pick, Start

Paste a video or playlist link, choose a quality, hit Start. Videos land in your Downloads folder (or any folder you pick).

[00:00:03] ⚙ features

Everything you need, nothing you don't

📃Playlist support

Paste a playlist link and add every video to the queue in one go — with a confirmation first, so no surprises.

🎚Quality per video

360p to 8K, or MP3 audio. Each queued video remembers its own quality — mix and match freely.

📊Size estimates

See the estimated total size and watch-time of your queue before you download a single byte.

🧵Batch queue

Queue 5 or 500 videos and walk away. Live progress, skip, stop, and per-video status.

FFmpeg and the download engine ship inside the app. No Python, no command line, no PATH nonsense.

Your download folder and favorite quality are saved automatically between sessions.

[00:00:04] ❓ faq

Questions people actually ask

Windows says "Windows protected your PC" — is this a virus?

No. That warning appears for any app from an independent developer that isn't code-signed (certificates cost hundreds of dollars a year). Click More info → Run anyway. The full source code is public on GitHub, so you — or anyone — can read exactly what the app does.

Is it really free?

Yes — free and open source under the MIT license. No ads, no accounts, no "premium version".

What if a video isn't available in the quality I picked?

You automatically get the best quality that actually exists. Picking 4K on a 1080p video just gives you the 1080p — never an error.

Does it work on Mac or Linux?

The one-click download is Windows-only for now. Mac/Linux users can run the Python script from GitHub directly.
